Observability

      
What Prometheus Tracks

      
5 custom metrics instrumented directly into the FastAPI application code. Prometheus scrapes the /metrics endpoint every 15 seconds via a Kubernetes ServiceMonitor.

    


    

      

        
🔢

        
prediction_requests_total

        
Counter · labeled by status

        
Total requests served, split by success/error and model version. Use rate() in PromQL to get requests/sec.

      

      

        
⏱️

        
prediction_latency_seconds

        
Histogram · 9 buckets

        
Request latency distribution from 5ms to 2.5s. Enables p50/p95/p99 SLO tracking via histogram_quantile().

      

      

        
🎯

        
prediction_confidence_score

        
Histogram · 10 buckets

        
Model confidence distribution across predictions. Drift in this metric signals model degradation over time.

      

      

        
⚠️

        
high_risk_predictions_total

        
Counter · business metric

        
Count of high-risk classifications. A sudden spike here signals an anomalous batch of applicants.

      

      

        
💚

        
model_loaded

        
Gauge · health signal

        
Binary 0/1 gauge. Prometheus alert fires if this drops to 0 — pod is up but model failed to load.

Technology Stack

      
Built With

      
Every tool chosen for a specific production reason — not just to pad a tech list.

    

    

      

        
☸️

        
Kubernetes (k3s)

        
Orchestration

        
Lightweight K8s on AWS EC2. Handles pod scheduling, self-healing, HPA autoscaling, and service discovery. k3s chosen for single-node resource efficiency.

      

      

        
⚡

        
FastAPI

        
Model Serving

        
Async Python web framework serving predictions. Pydantic schemas for input validation, lifespan context manager for model loading, uvicorn for ASGI serving.

      

      

        
📊

        
MLflow

        
Experiment Tracking

        
Logs training runs, metrics, parameters, and model artifacts. Provides the Model Registry for versioning. Running as a Kubernetes Deployment with SQLite backend.

      

      

        
🔥

        
Prometheus

        
Metrics Collection

        
Deployed via Helm (kube-prometheus-stack). Scrapes /metrics every 15s via a ServiceMonitor CRD. Stores time-series data for PromQL querying.

      

      

        
📈

        
Grafana

        
Visualization

        
6-panel dashboard with PromQL queries for request rate, p95 latency, confidence distribution, high-risk counter, and model health gauge.

      

      

        
🐳

        
Docker

        
Containerization

        
Multi-stage builds keep images lean. Non-root appuser for security hardening. Health checks for Kubernetes liveness/readiness probes.

      

      

        
🤖

        
scikit-learn

        
ML Model

        
Gradient Boosting Classifier in a sklearn Pipeline with StandardScaler. Trained on 1,000 synthetic credit applications. 88.2% ROC-AUC, ~10ms inference.

      

      

        
☁️

        
AWS EC2

        
Infrastructure

        
t3.large (8GB RAM) running the full stack. Security groups, key pairs, and EBS volume managed via AWS CLI. Upgraded from t3.medium to resolve OOM pressure.

FastAPI + scikit-learn serving predictions with sub-10ms p95 latency measured live via Prometheus histogram_quantile() in Grafana.

Pod replicas scraping UP in Prometheus

        
Both prediction API pods confirmed healthy via Prometheus Target Health — ServiceMonitor correctly discovered and scraped both instances.

Counter, Histogram, and Gauge types covering request rate, latency distribution, confidence scores, business risk signals, and model health.
